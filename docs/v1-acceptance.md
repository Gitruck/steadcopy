## 一、先做这三件（十分钟）

### 1. 核对来源再装

```powershell
Get-FileHash .\稳拷_0.1.0_x64-setup.exe -Algorithm SHA256
```

与 `release/SHA256SUMS.txt` 逐字比对。会提示未知发布者，这是预期的（没买签名证书）。

### 2. 什么都不配，直接拷一次

**这是这轮改造的重点：拷贝不再需要先建项目、先配预设。**

插卡 → 指认类型（或直接点「就拷这一次」）→ 选一个拷到哪儿 → 开始。项目那一栏会预填「我的素材」，
一路回车过去就行，稳拷会替你建出来。

**目的地是唯一必填的东西**——拷到哪儿只有你知道，其余全有默认值。

### 3. 让它记住

拷贝跑起来之后，进度条下面会出现一行提示：

> 以后「扩展」插上，就自动拷进「我的素材」？　`记住这个做法`

点一下就生成预设，不跳编辑器。范围默认「就这张卡」（最窄，误伤不了别的卡），可以改成「同一类设备」。
该设备还没指认类型的话，这条提示里会一并让你选。

**这行提示只在「这次的做法和已记住的不一样」时出现**——完全照预设跑就闭嘴。

### 4. 专业路线原样还在

`设置 → 项目 → 新建 → 配多目的地 → 配路径模板` 这条没有任何简化，路径模板有实时预览
（预览调的是后端同一个渲染函数，不是前端另写一份，所以预览与实际不会漂）。两条路产出同一种项目。

## 二、值得专门试的几处

### 增量与续传

拷完再插一次同一张卡 → 应该报「没有新素材」。往卡里加一个文件再插 → 只拷那一个，其余跳过。
判定依据是「清单有记录 + 当初校验通过 + 目的地上文件现在还在」三条同时成立，**不看 mtime**
（exFAT 的 mtime 是 2 秒粒度，靠它判增量迟早出事）。

拷到一半拔卡 → 任务报可重试族错误；重插后继续，已完成且校验通过的不会重拷。

### 校验是真的在校验

这是整个工具的立身之本，值得单独确认一次：拷完之后，**手工改动目的地里某个文件的一个字节**，
然后在台账里对那次任务点「复验」。结果应该是那个文件进「丢失」，同时多出一个「新增」
（内容变了 = 原内容找不到了 + 出现了一个清单没记录的文件）。

复验给的是**四态并列**：一致 / 已移动 / 丢失 / 新增。只有「新增」不算失败——多出文件本身不是错误。

> 需要说明的一点：读回校验用 `FILE_FLAG_NO_BUFFERING` 绕过页缓存。
> 但**上面这个篡改测试并不能证明缓存被绕过**——从文件系统改文件同时也会更新页缓存。
> 真正证明缓存绕过要在虚拟机里做（危险轨 D-001）。安全轨里不声称已证明，这是本项目对自己的要求。

### 报告

拷完点「查看报告」，报告在应用内直接渲染（沙箱 iframe），也可以「在浏览器中打开」再打印成 PDF。
报告是单文件 HTML、样式内联、离线可开，跟着数据一起落在目的地的 `steadcopy/` 目录里——
整个目录搬走，凭证跟着走。

### 暂停 / 继续 / 取消

拷大文件时点暂停，进度应该停住；再点继续，从暂停点接着走，最终结果与不暂停一致。
**暂停中点取消要能立刻停**——「暂停了忘了继续」不应该让取消按钮失效。

### 安全弹出

设备卡片上的「安全弹出」走的是锁定 → 卸载 → 弹出，不依赖任何外部程序。
剪辑软件还开着卡上素材时会失败，失败信息会告诉你去关掉占用它的程序——这是正常的，不是 bug。

### 「插卡没反应」的每一种原因

这是这类工具最高频的困惑，所以九种结论都能被呈现出来。可以刻意制造几种试试：

| 制造方式 | 应该看到 |
|---|---|
| 插一张没见过的卡 | 请先指认它是什么 |
| 把设备标成「忽略」再插 | 静默，但设备页的「已忽略」分组里能找到它 |
| 停用全部预设再插 | 没有匹配的预设任务 |
| 删掉项目再插 | 预设还没有可用的项目 |
| 插一张空卡 | 卡上没有可拷贝的素材 |
| 拷完再插 | 没有新素材 |
| 目的地塞满 | 空间不足，并给出所需 / 可用 |

### 危险区

设置页最下面，视觉隔离，默认全关。开任何一项都要过倒计时确认（默认 30 秒，最小 10 秒），
开着的时候**每个页面顶部常驻提示条**，免得忘了自己开过。

- **跳过插卡确认**：开了之后已分类设备插上直接开跑。**未分类设备仍然绕不过指认**——
  拷贝是可恢复的，往不知道是什么的设备上自动动手不是。
- **拷完自动格式化**：只在「全部目的地完成 + 全部校验通过 + 零失败 + 未取消」时才提议，
  且提议之后仍然要走完整的倒计时 + 手输确认串。任何一条不满足都会告诉你**为什么没触发**。

## 三、需要你安排虚拟机的部分（本机绝不跑）

格式化是唯一会不可逆销毁数据的能力。按你定的规矩，它的验收**不在这台机器上做**。

SOP 在 [`docs/danger-tests.md`](danger-tests.md)，四条：D-001（无缓冲读回确实绕过缓存）、
D-002（格式化保留原文件系统与卷标）、D-003（安全链拦下系统盘与目的地盘）、D-004（格式化留痕四态齐全）。

三重闸门（`#[ignore]` + `STEADCOPY_DANGER_TESTS=1` + `STEADCOPY_DANGER_TARGET` 白名单）都在，
靶标解析为系统盘或本机固定盘会直接中止。

**在 D-001..D-004 通过之前，发布说明里不应宣称格式化功能可用**（门控 R5）。

## 四、刻意没做的，和还没做的

分清楚这两类很重要。

### 刻意没做（是选择，不是遗漏）

- **不联网**。没有账号、没有遥测、没有自动更新，也没有后台更新检查。代价是新版本要你自己去看。
  这条有结构性保证：依赖树里根本没有 HTTP 客户端，有测试盯着。
- **不做 mac 版**。架构位置留着了（平台 trait + 非 Windows 返回 `Unsupported`），但没做。
- **不做批量格式化**，不做低级格式化 / 分区表操作 / 安全擦除。
- **手机不做可信备份**。安卓与 iPhone 在 Windows 上走 MTP：没有块级校验、文件大小可能被 32 位截断、
  时间戳不可信。建议手机用 SD 卡或外置 SSD 走读卡器。
  另外 iPhone 默认会把 HEIC/HEVC 转码后再传给电脑——**默认设置下你拿到的本来就不是原文件**。
- **便携版不含 WebView2 运行时**。安装包含（离线完整版），便携版靠系统自带。

### 还没做（V1 的边界，下一轮的候选）

界面侧还有一批能做但这轮没做的，按我判断的价值排序：

| 缺什么 | 影响 |
|---|---|
| **英文界面有中文残留** | 预设页、设备页、台账页、设置页其余分区、复验四态面板、格式化确认框还没走词典；报告 HTML 与命令行大部分输出也还是中文。**只会退回中文，不会变空白** |
| 托盘常驻 | 关掉窗口就停止监听，插卡即跑只在窗口开着时有效 |
| 首次运行向导 | 现在靠空态提示 + 「就拷这一次」兜底，能走通但不够顺 |
| 任务队列（多任务并列呈现） | 现在一次跑一个，第二张卡会排队并提示，但看不到队列 |
| 每个目的地各自的进度条 | 现在是合并进度 |
| 台账按日期 / 设备 / 项目筛选 | 现在只有「只看有失败的」 |
| 确认卡片就地改参数 | 现在是「改一下再拷」跳到临时拷贝面板，多一次点击 |
| 素材类别配置、目录模板树形编辑器 | 整卡镜像是默认且是对的，分类过滤属于进阶用法 |
| 开机自启、系统通知的分类开关 | 通知本身有（完成 / 部分失败 / 取消），但不能分别关 |
| 命令行的沉淀入口 | `preset from-task` 还没做，界面里有 |

这些都在 `openspec/changes/add-steadcopy-app/tasks.md` 里逐条标着未完成，没有被悄悄勾掉。

## 五、审查的时候可以重点看这几处

如果你要抽查代码，这几个地方是我认为最值得看的——它们要么是前身栽过跟头的地方，
要么是我自己在过程中改过判断的地方：

| 位置 | 为什么值得看 |
|---|---|
| `crates/steadcopy-core/src/engine/hasher.rs` | `HashValue` 是定长值类型不是 String，「空哈希 == 空哈希 = 通过」这句代码**写不出来** |
| `crates/steadcopy-core/src/engine/verify.rs` | 校验失败是 `Err` 而不是「不相等」，没有降级路径 |
| `crates/steadcopy-core/src/device/format.rs` | 安全链 G1–G4；`removability()` 返回 `Result` 不是 bool，查询失败一律判拒绝——**这正是前身出事的那一行** |
| `crates/steadcopy-core/src/organize/path_template.rs` | 两级净化：值级净化挡分隔符（防路径穿越），段级净化挡保留名 |
| `crates/steadcopy-core/src/preset/arrival.rs` | 六步编排返回枚举而不是 `Option`，每种「没跑起来」都能说出口 |
| `clippy.toml` | 把「静默降级」的写法机械禁掉；加上这条规则当场揪出了 10 处真实的吞错 |
| `crates/steadcopy-core/tests/release_gate.rs` | 发布门控里能自动化的那部分：文档不教人关杀软、依赖无 GPL、无 HTTP 客户端、前端不绕过 bridge |
| `docs/facade-contract.md` | 跨层契约；前端零业务逻辑这条铁律的具体形态 |
| `crates/steadcopy-core/src/task/adhoc.rs` | 临时拷贝产出的 `TaskSpec` 与预设路径**完全同构**——下游分不出来源，就没人能为「临时」写捷径 |
| `crates/steadcopy-core/src/preset/sinking.rs` | 沉淀默认最窄范围；放宽的代价由未来每一次插卡承担 |
