## 这个工具是干嘛的

拍完素材，卡上的东西得拷到硬盘里。这件事看起来就是复制粘贴，但有两个坑：

**第一个坑：复制粘贴不告诉你有没有拷坏。** Windows 的复制不做校验。一张老卡、一根接触不良的线、一块开始坏道的硬盘，都可能让某个文件在拷贝过程中悄悄变成一堆乱码——而资源管理器会显示「复制完成」。等你剪辑的时候打不开那条素材，卡已经格了。

**第二个坑：拷完了不知道到底有没有拷全。** 一张卡几百个文件，肉眼数不过来。

稳拷做的就是这两件事：**拷的时候边拷边算，拷完从硬盘里重新读一遍核对**，然后给你一张写着人话的报告。

拷完之后你手里有一份「凭证」，跟素材放在一起。半年后客户问「我那天的素材还在吗」，你可以对着凭证重新核一遍，告诉他每一个文件是好的、还是丢了、还是被谁挪走了。

## 第一次用：三分钟

### 1. 装上

从官网或 GitHub 下载安装包。**Windows 会弹一个「未知发布者」的警告**——这是因为我们还没买代码签名证书（一年好几千，开源项目暂时不花这个钱），点「更多信息 → 仍要运行」就行。

想更稳妥的话，下载页有一串 SHA-256 校验码。在下载目录开 PowerShell：

```powershell
Get-FileHash .\稳拷_0.1.0_x64-setup.exe -Algorithm SHA256
```

跟页面上那串逐字对一下，一样就是官方的。

> ⚠️ **任何时候都不要为了运行这个程序去关掉杀毒软件。** 如果被拦了，先核校验码，然后针对这一个程序加信任就行。

### 2. 插卡

把卡插上（读卡器、相机直连都行）。稳拷会弹一张卡片。

**第一次插某张卡，它会先问你「这是什么」**——摄影卡、录音卡、还是素材盘。

这一步不能跳过，因为它还不认识这张卡。你也可以选「就拷这一次」，那就不用给它贴标签，拷完了事。

### 3. 拷

指认完之后，卡片上会显示：

- 这张卡上有多少个文件、一共多大
- 要拷到哪里去（完整路径，不是「D 盘」这种含糊说法）
- 那个盘还剩多少空间、够不够

**确认没问题，点「开始拷贝」。**

拷的过程中会有两条进度条：**拷贝**和**校验**。校验那条是在从硬盘里把刚写进去的东西重新读出来核对——这是这个工具存在的理由，别关它。

拷完给你一张报告，能直接在软件里看，也能在浏览器里打开、打印成 PDF 发给客户。

## 让它记住你的习惯

上面那套走完一遍，你会发现每次都要选一样的东西。所以：

**拷贝跑起来的时候，进度条下面会出现一行提示：**

> 以后「A7M4」插上，就自动拷进「婚礼」？　`记住这个做法`

点一下，以后这张卡插上就直接弹确认卡片，参数都预填好，你点一下「开始拷贝」就行。

这就是「预设」。你也可以去「预设」页手动配，但一般用不着——**让它从你实际做过的事情里学，比让你先去想清楚要容易得多**。

记住的范围默认是**「就这张卡」**。你可以改成「所有摄影卡」，但建议先从窄的开始——万一记错了，影响面小。

## 「项目」是什么

一个项目 = **一组目的地 + 一套目录结构**。

比如你接了个婚礼的活，素材要同时进工作盘和备份盘，目录按「项目/日期/设备」分。这一套设置就是一个项目。下次拍另一个活，新建一个项目就行。

**你也可以完全不管它。** 第一次拷的时候，项目那一栏会自动填一个「我的素材」，直接过就行——稳拷会替你把它建出来。等你需要多个目的地、需要改目录结构的时候，再去「设置 → 项目」细配。

## 插了卡没反应？

这是这类工具最常见的困惑，所以稳拷把每一种原因都写出来了。工位页上会告诉你是哪一种：

| 你看到的 | 意思 | 怎么办 |
|---|---|---|
| 请先指认它是什么 | 从没见过这张卡 | 选个类型，或者「就拷这一次」 |
| 该设备已被忽略 | 你以前把它标成忽略了 | 去「设备」页的「已忽略」分组里取消 |
| 没有匹配的预设任务 | 没有规则管这张卡 | 点「就拷这一次」，拷完顺手记住 |
| 没有新素材 | 这张卡以前拷过，而且校验通过了 | 正常，不用管 |
| 目的地空间不足 | 硬盘满了 | 换个目的地 |

**每一种都带一个按钮告诉你下一步干什么**，不会只是干告诉你一句就没了。

## 拷完之后

### 看报告

台账页里每一次拷贝都有记录，点「报告」看详情：拷了哪些文件、每个文件的校验值、有没有失败的。

### 复验

这是稳拷比复制粘贴强的地方。点「复验」，它会把目的地的文件重新读一遍、重新算一遍，跟当初的凭证对比，给你四种结果：

- **一致** — 好的
- **已移动** — 文件还在，但换地方了（你自己整理过目录）
- **丢失** — 找不到了，或者内容变了
- **新增** — 多出了凭证里没记的文件（这不算错，只是告诉你一声）

半年后客户来问，跑一次复验就有答案。

### 安全弹出

设备卡片上有「安全弹出」。它做的是「锁定 → 卸载 → 弹出」三步——**只做到最后一步就拔卡，写缓存可能还没落到卡上**。这也是为什么直接拔卡有时候会出问题。

如果弹不出来，通常是剪辑软件还开着卡上的素材，关掉再试。

## 危险区

设置页最下面有个红框区域，默认全关：

- **跳过插卡确认** — 插上就直接开跑，不问了。开了之后每个页面顶部会一直提醒你开着
- **拷贝完成后格式化源卡** — 只在「全部目的地完成 + 全部校验通过 + 零失败」时才会提议，而且提议之后还要等倒计时、还要手动输一遍卡的名字

**格式化是唯一会永久删数据的功能。** 它有一整套前置检查：是不是可移动介质、是不是你配的目的地盘、上面有没有任务在跑、台账里有没有这张卡「拷完且校验通过」的记录。任何一条不满足都拒绝执行。

即便如此——**格式化之前，自己再确认一遍备份在哪儿。**

## 命令行

如果你要批量跑或者接进自己的流程，稳拷有命令行版本（安装目录里的 `steadcopy.exe`，便携版包里也有）：

```bash
steadcopy devices                                    # 看看有哪些卷、哪些能当源
steadcopy plan E:\ -d D:\素材 -p 婚礼                 # 预演，什么都不写
steadcopy copy E:\ -d D:\素材 -d F:\备份 -p 婚礼      # 真拷
steadcopy audit <清单.json>                          # 复验
steadcopy watch                                      # 守着，插卡即按预设跑
```

加 `--json` 就是机读输出，方便接脚本。

## 几件值得知道的事

**手机不建议直接拷。** 安卓和 iPhone 在 Windows 上走的是 MTP 协议，没有盘符、不是文件系统对象，做不了块级校验，文件大小还可能被截断。用 SD 卡或移动硬盘走读卡器最稳。

**iPhone 默认会转码。** 设置 → 应用 → 照片 → 传输到 Mac 或 PC，如果是「自动」，手机会把 HEIC/HEVC 转成 JPEG/H.264 再给电脑。**转码发生在手机上，任何拷贝工具都躲不掉**——要原片就改成「保留原始格式」。

**整卡镜像是默认。** 稳拷不挑文件，除了系统垃圾（缩略图缓存那些）全拷。因为相机会生成一堆配套文件——佳能的 `INDEX.MIF`、Insta360 的成对 `.insv`——少一个，剪辑软件里整条素材就废了。

**稳拷不联网。** 没有账号、没有遥测、没有自动更新。新版本得你自己去看。

## 出问题了怎么办

界面上任何一处报错，都能复制一段诊断信息。连同「设置 → 关于」里的构建标识一起发过来就行。

如果是某一页白了/报错了，其他页还能正常用——出错的那一块会显示可复制的诊断信息，不会把整个窗口带走。
