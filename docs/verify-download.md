# 核对安装包来源

稳拷目前**没有购买代码签名证书**，所以首次运行时 Windows 会提示「未知发布者」。
这是预期行为，不代表程序有问题——但你**应该**核对校验码来确认拿到的确实是官方构建。

## 怎么核对

在下载目录打开 PowerShell，执行：

```powershell
Get-FileHash .\稳拷_0.1.0_x64-setup.exe -Algorithm SHA256
```

把输出的 `Hash` 与下面三处**任一**公示的值逐字比对（三处内容一致）：

1. GitHub Releases 页面的 `SHA256SUMS.txt`
2. 官网下载页
3. 应用内「关于 → 安装包校验码」

**一致才安装。** 不一致说明文件在传输中损坏，或者你拿到的不是官方构建——国内下载站二次打包是真实存在的事，请回官方渠道重新下载。

## 不要做的事

**任何时候都不要为了运行本程序去关闭 Windows Defender 或第三方安全软件。**

一个备份工具要求你降低系统防护，本身就自相矛盾。如果安全软件报警：

1. 先按上面的方法核对校验码；
2. 校验码一致的话，向该安全厂商**提交误报反馈**（各家都有开发者/用户误报申报入口）；
3. 同时可以在本项目的 issue 里说一声，方便我们主动去申报白名单。

## 为什么安装包这么大

约 200 MB，因为把 **WebView2 运行时完整打进去了**。

片场、外景、机房经常没网。安装一个备份工具时才发现「需要联网下载组件」是不可接受的，
所以我们选择把体积背上。装完之后应用本体只有约 10 MB。
